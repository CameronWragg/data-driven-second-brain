# Implement the Second Brain in Rust

The Second Brain is written in Rust rather than TypeScript. Query latency would be similar in either language because SQLite and the embedding runtime do the heavy work in native code, but Rust gives near-instant startup when an Agent launches the MCP server, a small memory footprint, faster bulk indexing, and distribution as a single dependency-free binary, which matters for the product. We accept slower iteration than TypeScript in exchange. Elixir was rejected because its strengths (long-lived concurrent processes) suit a hosted server rather than a quick-launch local tool.
