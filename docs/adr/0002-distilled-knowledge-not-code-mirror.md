# Store distilled knowledge about code, not a copy of the code

The Second Brain records what is not obvious from reading source code (architecture, decisions, conventions, gotchas) and points at code by Repository, path and commit rather than chunking and embedding the source itself. Agents already have the checked-out Repository and code-search tools, and a code mirror would make the Second Brain heavy and permanently stale. Mirroring code may arrive later as an optional plugin, but it is not part of the core model.
