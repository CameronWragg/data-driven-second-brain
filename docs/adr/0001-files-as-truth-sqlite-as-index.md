# Plain files are the source of truth; SQLite is a disposable index

The Second Brain's canonical data lives as plain structured files in a folder the owner controls, keeping it human-readable, diffable and portable. A single SQLite database beside them holds the full-text index, embedding vectors and Links for fast in-process hybrid search; it is derived entirely from the files and can be deleted and rebuilt at any time. We chose this over a database-as-truth because owning readable data matters more than the small write-path cost of updating both, and query performance is identical since reads only touch SQLite.
